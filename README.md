### ⚡ About Me

> **"Bridging scalable software architecture with offensive & defensive security engineering."**

I am an engineer operating across **Full-Stack Systems**, **DevOps & Cloud Infrastructure**, **AppSec & Vulnerability Management**, and **Reverse Engineering & Binary Analysis**. I approach every problem with a **Dual Mindset (Builder + Auditor)**: building resilient, high-performance systems while rigorously auditing threat vectors, privilege boundaries, and edge cases.

- 🏗️ **Architecting Robust Systems**: Clean Architecture, strict type safety, zero unhandled edge cases.
- 🛡️ **AppSec & Threat Modeling**: Zero-Trust design, STRIDE Threat Modeling, OWASP Top 10 mitigation, continuous CVE triage.
- 🔬 **Reverse Engineering**: Dynamic instrumentation (Frida hooks, SSL unpinning), decompilation & CFG analysis (Ghidra, Rizin, GDB).
- 🤖 **AI & Agentic Workflows**: Model Context Protocol (MCP) tooling, autonomous agent pipelines, and local AI orchestration.
- 🐳 **Hardened DevOps**: Non-root minimal containerization, CI/CD pipelines, and secure cloud infrastructure.
